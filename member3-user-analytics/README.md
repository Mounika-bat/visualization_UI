# User Analytics

## UI Pattern

User Analytics Dashboard.

## Purpose

This dashboard provides information about user growth, activity and engagement.

## Main Features

- Total Users
- New Users
- Active Users
- Returning Users
- User Growth
- User Distribution
- User Activity
- Time Filter

## Technologies

- HTML5
- CSS3
- JavaScript

## JavaScript Functionality

The time filter dynamically changes user analytics values.

## How to Run

Open `index.html` in a browser or use VS Code Live Server.
