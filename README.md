# InsightHub - Analytics & Data Visualization UI Collection

## Project Description

InsightHub is a collection of modern Analytics and Data Visualization UI templates developed using HTML, CSS and JavaScript.

The project contains four different analytics dashboards.

## Team Members

- Member 1 - Analytics Dashboard
- Member 2 - Revenue Analytics
- Member 3 - User Analytics
- Member 4 - Real-Time Analytics

## UI Templates

### 1. Analytics Dashboard

Contains:
- Total Revenue
- Total Users
- Total Orders
- Conversion Rate
- Revenue Chart
- User Growth
- Recent Activity

### 2. Revenue Analytics

Contains:
- Total Revenue
- Monthly Revenue
- Average Revenue
- Growth Rate
- Monthly Revenue Chart
- Revenue Categories
- Top Revenue Sources

### 3. User Analytics

Contains:
- Total Users
- New Users
- Active Users
- Returning Users
- User Growth
- User Activity
- User Distribution

### 4. Real-Time Analytics

Contains:
- Live Users
- Live Orders
- Live Revenue
- Live Conversion Rate
- Live Activity
- Recent Events
- System Status

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project in VS Code.
3. Open `index.html`.
4. Use Live Server or open the file directly in a browser.
5. Select any dashboard.
