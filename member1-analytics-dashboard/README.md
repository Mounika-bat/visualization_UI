# Analytics Dashboard

## UI Pattern

Analytics Dashboard.

## Purpose

This dashboard provides an overview of important business performance metrics.

## Main Features

- Total Revenue
- Total Users
- Total Orders
- Conversion Rate
- Monthly Revenue
- Performance Indicators
- Recent Activity
- Time Filter

## Technologies

- HTML5
- CSS3
- JavaScript

## JavaScript Functionality

The time filter dynamically changes the KPI values.

## How to Run

Open `index.html` in a browser or use VS Code Live Server.
